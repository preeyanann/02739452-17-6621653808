ระดับ 1DAG fuel_price_pipeline: extract → transform (merge) → load ลง PostgreSQL (fueldb) และเว็บ Flask แสดงตารางกับกราฟครบ
ระดับ 2ดึง 3 แหล่งขนานกันใน TaskGroup extract, แปลงชื่อน้ำมันทุกแหล่งให้เป็น schema เดียว (price_date, brand, fuel_code, price), ใช้ UPSERT ON CONFLICT DO UPDATE (รันซ้ำ 5 รอบ จำนวนแถวคงที่ 1,830), เว็บมี KPI 5 ตัว และตัวกรองชนิดน้ำมัน ผู้ค้า และช่วงวันที่ครบ
ระดับ 3• แหล่งล่ม: merge_sources ใช้ trigger_rule=all_done และรวมเฉพาะแหล่งที่สำเร็จ ทดสอบด้วย Variable simulate_down=bangchak_api ได้ผลรอบนั้นเป็น partial และยังโหลดได้ครบ 1,830 แถว
• ตัดซ้ำข้ามแหล่ง: ราคา PTT มีทั้งจาก ปตท. และ สนพ. ส่วน BCP มีทั้งจากบางจากและ สนพ. จึงเลือก 1 แถวต่อ (วัน, ผู้ค้า, น้ำมัน) โดยให้แหล่งของเจ้าของแบรนด์ชนะ (2,206 แถวดิบ → 1,920 แถว)
• Data Quality + branch: ตรวจช่วงราคา 10–100 บาท, วันที่ในอนาคต และราคาที่ต่างจากมัธยฐานของผู้ค้าอื่นเกิน 15% ถ้าไม่ผ่าน DAG จะแตกไปทาง quarantine_bad_rows แล้วย้ายแถวไปตาราง dq_rejects (พบราคา ESSO ผิดปกติ 90 แถว)		ครบ

2. ปัญหาที่พบและวิธีแก้

ปัญหา / อาการวิธีหาสาเหตุวิธีแก้
1. ตารางราคาบนเว็บ สนพ. มีแต่ 30.00 ทุกช่อง อ่าน HTML ที่ดึงมาด้วย requests พบว่าเป็นค่า placeholder และราคาจริงถูกเติมด้วย JavaScript ภายหลัง ซึ่งใช้ Selenium ไม่ได้ จึงหา iframe ในหน้าเดียวกันจนพบหน้ารายงาน ASP.NET ropbydaypublic.aspx scrape ฟอร์มแทน: GET หน้าเพื่ออ่าน hidden field (__VIEWSTATE, __EVENTVALIDATION) แล้ว POST TbxToDate ได้รายงานรายวันที่ย้อนหลังได้ และมีครบทุกผู้ค้า
2. scrape สนพ. ล้มเหลวเป็นบางครั้ง ด้วย ChunkedEncodingError: IncompleteRead ดู traceback ใน log ของ task พบว่าเซิร์ฟเวอร์ตัดการเชื่อมต่อระหว่างส่งหน้า 250 KB ซึ่ง urllib3 Retry ไม่ครอบคลุมกรณีที่ตัดกลาง body เขียน _with_retry() ลองใหม่ 3 ครั้งแบบ backoff และแบ่ง scraping เป็น task ละวัน (Dynamic Task Mapping, ขนานไม่เกิน 4) วันที่ล้มเหลวจึงไม่ทำให้วันอื่นล้มตาม
3. ราคาบางจากวันที่ 22 ต.ค. ไม่ตรงกับ สนพ. (41.44 กับ 42.04) ทำให้กราฟมีจุดตก เทียบแถวที่ซ้ำกันข้ามแหล่งใน stg_fuel_prices แล้วอ่าน JSON ของบางจากอีกครั้ง พบว่า PriceYesterday คือราคาก่อนการปรับครั้งล่าสุด (วันประกาศ OilPriceDate) ไม่ใช่ราคาของ "วันนี้ − 1" ใช้ PriceYesterday กับวันที่ OilPriceDate ลบแถวผิดใน staging แล้วรันใหม่ ผลคือราคาตรงกันทุกวัน การเก็บคอลัมน์ sources ไว้ช่วยให้ตรวจไขว้แบบนี้ได้
